# 接口使用说明

首页地址：http://127.0.0.1:8000/
接口测试页面：http://127.0.0.1:8000/docs

普通聊天使用 POST /chat，知识库聊天使用 POST /rag_chat。
两个接口都接收 JSON，字段 question 是必填的问题文本，session_id 是可选的会话编号。

请求示例：

```json
{"question": "项目使用什么模型？", "session_id": "user001"}
```

成功响应包含 mode、session_id、question、answer、sources 五个字段。
answer 是模型生成的回答。sources 是检索命中的片段列表，
每个片段包含 id、title、score。普通聊天以及知识库模式下的简单问候返回空列表。
如果首次请求未提供 session_id，后端会生成编号并返回。

GET /kb_docs 返回文档目录中的文件名列表 documents 和文件数量 count。
查看文件列表不会构建索引；修改资料后需要运行 backend/build_kb.py。
