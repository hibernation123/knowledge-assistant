# 知识库问答助手项目说明

本项目使用 FastAPI 提供后端接口，使用原生 HTML 和 JavaScript 提供前端页面。
前端由后端的首页接口提供，通过同一地址调用聊天接口。

模型在本机 Ollama 中运行。聊天模型是 qwen2.5:7b，向量模型是 bge-m3。
普通聊天直接调用聊天模型生成回答。
知识库聊天先将问题转成向量，计算问题向量与文档片段向量的余弦相似度，
最多取相似度最高的三个片段作为参考资料，再由聊天模型生成回答。
参考来源的 score 是余弦相似度，数值越大表示向量越相似，不是回答正确率。

知识库原始资料放在 backend/kb_docs 中，支持 UTF-8 编码的 .md 和 .txt 文件。
运行 backend/build_kb.py 后，会将文本片段和向量保存到 backend/kb.db。
修改文档后必须重新运行构建脚本，问答使用的索引才会更新。
网页上的“查看知识库文档”按钮仅显示目录中的文件名，不触发索引重建。

当前版本在模型完整生成回答后一次性返回 JSON，尚未实现流式输出。
session_id 会传回前端，但后端尚未保存或读取聊天历史，因此没有多轮记忆。
知识库模式的简单问候会直接交给聊天模型回应，不检索文档。
